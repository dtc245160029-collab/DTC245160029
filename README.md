# Booking Tour System

Website đặt tour du lịch triển khai bằng Docker Compose.

## Công nghệ
- Node.js và Express
- PostgreSQL
- pgAdmin
- Nginx
- Prometheus và Grafana
- Loki và Promtail

## Chức năng
- Xem danh sách tour du lịch
- Xem chi tiết tour và lịch trình
- Đặt tour
- Quản lý dữ liệu tour và đơn đặt tour

## Triển khai
Sử dụng Docker Compose để quản lý các dịch vụ.
